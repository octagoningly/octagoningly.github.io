Obsidian 配置

一、图片附件管理

（1）安装第三方插件 Custom Attachment Location，修改以下配置：

  1. Move/Renames → 附件重命名模式：选择「全部」
  2. Advanced → Markdown 链接格式：填入 assets/{{noteFileName}}/{{generatedAttachmentFileName}}

（2）安装第三方插件 Advanced Rename and Delete Handler，修改以下配置：

  1. Should update file name aliases（是否更新文件名别名）：勾选
  2. Should rename attachment folder（是否重命名附件文件夹）：勾选
  3. Should rename attachment files（是否重命名附件文件）：勾选

（3）在 Obsidian 自带设置 文件与链接 中：

  1. 使用 Wiki 链接：取消勾选
  2. 内部链接类型：选择「基于当前笔记的相对路径」

二、使用技巧

  1. 通过左侧边栏的「大纲」视图可快速浏览当前笔记的结构。
  2. 打开命令面板（左侧图标或快捷键 Ctrl/Cmd + P），搜索并执行命令 Custom Attachment Location: Delete unused attachments in current note，即可删除当前笔记中未被引用的多余附件图片。

三、笔记同步方式

（1）使用 Git 插件实现多端同步：

  1. 先将本地笔记文件夹初始化为 Git 仓库。
