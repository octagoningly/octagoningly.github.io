Cool Music v0.2.6 发布：本地优先的多源音乐播放器

一、这是什么

Cool Music 是一个面向 Android 的本地优先音乐播放器，基于开源项目 NeriPlayer（GPL-3.0）二次开发。

它的核心主张很简单：播放器应该服务于你自己的曲库和授权，而不是反过来。

  • 本地歌单、收藏、最近播放、播放统计默认全部留在设备里；
  • 需要同步时，写进你自己配置的 GitHub / WebDAV 远端，不经过开发者服务器；
  • 在线能力（搜索、取流、歌词、封面）走你自己配置的音源接口或平台授权。
项 值
应用包名 moe.ouom.coolmusic（与上游独立，可共存安装）
技术基线 Jetpack Compose + Media3，Kotlin / Java 17
最低版本 Android 9（minSdk 28）
许可证 GNU GPL v3

四、这次 v0.2.6 修了什么

这个版本没有堆新功能，主要是把之前积累的一批用户能直接感知到的体验问题清掉。

4.1 连点「下一首」不再转圈

之前连续快点下一首时，播放键会变成转圈状态一会儿。原因是播放路径在等后台的预取任务，而预取是串行下载多首的批量任务，等它等过了 UI 的 1 秒转圈阈值。

改了三处：

  • 播放路径不再阻塞等待预取任务（预取退化为纯旁路加速，命中就赚到）；
  • 连点切歌改为合并防抖，多次点击只真正解析一次；
  • 连点期间把预取窗口从 8 首缩到 2 首，不再越急越抢带宽。

4.2 进度条支持单击跳转

播放页进度条以前只能拖动，单击无反应。现在单击可直接跳到所点位置，拖动行为完全保留，两者互不冲突。

4.3 缓存相关问题（这块用户感知最强）

  • 图片缓存迁到持久化目录：以前放在 cacheDir，系统清缓存或存储紧张时会整体删掉，导致第二次冷启动封面全部重新联网下载。现在和歌单数据一样持久化。
  • 清理缓存时同步释放 Coil 实例：以前只删目录文件，进程内已打开的缓存实例不失效，会出现「清了却没清干净」。
  • 列表封面增加加载占位：即使命中磁盘缓存，解码期间也是纯空白后突然淡入。现在有中性色占位，深浅色自适应。
  • 媒体库在线歌单列表持久化：网易云 / B站 / YouTube / QQ 的用户歌单列表以前只存内存，冷启动和弱网下直接空白。现在先展示磁盘缓存再后台刷新，换号自动隔离。

4.4 关屏再开启后误判离线

这个问题比较隐蔽：息屏 / Doze / 网络切换瞬间，activeNetwork 会短暂为 null，被判定为离线；而系统不一定会再补发 onAvailable，于是状态永久卡在离线，首页内容消失、探索页显示「网络不佳」，但实际网络是好的。

修复：回到前台时无条件重查真实网络状态、网络丢失延迟确认、activeNetwork 为空时用底层传输类型兜底。同时离线时探索页改为展示磁盘缓存而不是整页空白。

4.5 媒体库与探索页的滚动抽动

探索页上滑出现「发现」栏、媒体库下滑收起 Tab 行时，底层列表会抽一下。根因是滚动补偿形成了自激反馈环：补偿滚动改写了列表偏移量，而显隐判定读的正是同一个偏移量，于是补偿被当成用户手势 → 再次触发补偿。

修复方式是斩断反馈环：把探索页的「发现」栏改成网格的首个 item（与卡片共同滚动），媒体库的顶部留白改为恒定值，让列表滚动位置只由用户手势驱动。

4.6 设置与关于页

  • 进入设置二级页时，主页「设置」大标题立即隐藏，不再与返回栏叠成两层；
  • 关于页重做为可折叠大图标头部 + 流动渐变背景 + 开发者卡片（点开可就地展开 GitHub 链接）；
  • 播放页更多菜单放宽宽度，长文案不再折行。

五、核心能力一览

在线音源（本仓库的重点增强）

在上游网易云 / Bilibili / YouTube Music / 本地之外，新增 LX Music 风格第三方在线音源：

能力 说明
音源导入 支持 LX Music JSON 与 JS 脚本，JS 由内置 QuickJS 执行
优先播放 设置 → 在线听歌；播放页封面显示「在线音源」角标
匹配与回落 按歌名 / 歌手 / 时长打分，过滤伴奏与翻唱
跨平台兜底 主通道不可用时按 酷我 → 酷狗 → QQ 等搜原版取流
每日自动验证 GitHub Actions 每天搜索并验证候选音源，App 内可一键获取
搜索多引擎 探索页「在线」可选 QQ / 酷狗 / 酷我 / 网易云，默认仅 QQ

歌词与封面

  • 无歌词时从在线音源平台同步，也可从 QQ / 酷狗公开接口匹配；
  • 识别网易云占位歌词，避免空壳歌词挡住真实歌词；
  • 逐行 / 逐词（LRC、YRC、TTML）、翻译、音译、偏移、点击跳转、歌词卡片。

媒体库

  • 本地 / 收藏 / 网易云 / 网易专辑 / B站 / YouTube Music / QQ 多标签，支持自定义排序；
  • 外部歌单链接导入；
  • 已缓存歌曲独立入口，可离线播放。

上游保留的能力

多源播放（Media3）、本地媒体库、下载、播放音效（均衡器 / 倍速 / 响度）、USB 独占播放（UAC1.0 / UAC2.0）、桌面小组件、启动器快捷方式、悬浮歌词、状态栏歌词、GitHub / WebDAV 同步、播放统计、流量统计、一起听（可自建服务端）、崩溃日志与安全模式。

六、怎么配在线音源

  1. 设置 → 在线听歌
  2. 点「获取」读取 GitHub 每日验证清单，可查看、复制或直接导入通过自动验证的音源地址
  3. 也可以手动导入 LX JSON / JS 与你的服务地址
  4. 按需开启优先播放、音源封面 / 音源歌词，可用通道自检
  5. 探索页「在线」可免登录搜索单曲 / 歌手 / 歌单

[!NOTE]
在线音源不会绕过平台账号权限或版权限制。本项目不内置、不维护任何公共曲库或第三方音源地址。
